# 9本目「トレード事件簿」調査メモ（2026-11-10）

## トレードの仕組み
| 内容 | 出典 | 信頼度 |
|---|---|---|
| 統一契約書 第21条：球団が契約を他球団へ譲渡することを、選手はあらかじめ承諾する。だから日本ではノートレード条項は結べない（明らかになった例はない） | Wikipedia「ノートレード条項」、協約47条（統一契約書の条項は合意でも変えられない） | ○ |
| 1952〜1972年は「10年選手制度」で、条件を満たした選手にはトレードを拒否する権利があった | 同上 | ○ |
| トレードの期限は7月31日（野球協約108条）。8月1日からシーズン終了まではウエーバーを除き譲渡できない | NPB 発表の報道（デイリー 2026/7/31） | ◎ |
| 2026年は期限までに支配下選手のトレードが4件 | デイリー 2026/7/31 | ○ |
| 複数年契約中でもトレードできる（2009年 清水直行 ロッテ→横浜の例） | Wikipedia | ○ |
| 現役ドラフト：2022年から。出場機会の少ない選手の移籍を進める。各球団が2人以上を候補に出し、少なくとも1人を指名。2025年12月9日の第4回は12人が移籍 | ベースボールチャンネル、チケジャム | ○ |
| トレードの形：交換（何人対何人）、金銭（お金で譲る）、無償（お金も選手も受け取らない） | 一般 | ○ |

## 事件簿
### 1963年 世紀のトレード（山内一弘 ⇔ 小山正明）
- 1963年の暮れ、大毎（東京オリオンズ）の4番・山内一弘（31歳）と、阪神のエース・小山正明（29歳）の1対1（○ hb-nippon、Number）。
- 阪神は打線、大毎は投手を求めていた。FA のない時代、選手の意向は通らない（小山は「事前の相談がなかった」と不満）○。
- 1964年、山内のいる阪神はリーグ優勝、小山は移籍1年目に30勝で最多勝 ○（30勝は広く知られた記録）。

### 1975年 江夏豊（阪神 → 南海）
- 1975年オフ、江夏豊・望月充 ⇔ 江本孟紀・島野育夫・長谷川勉・池内豊 の2対4（○ Number ほか）。
- 南海の野村克也監督がリリーフ転向を説得。江夏は「リリーフの先駆け」に ○。
- 江本は南海の選手会主催のゴルフコンペの場で通告されたと回想 △（本人の回想）。

### 1978年 田淵幸一（阪神 → 西武）
- 1978年オフ、田淵幸一・古沢憲司 ⇔ 真弓明信・若菜嘉晴・竹之内雅史・竹田和史 の2対4（○ hb-nippon、SPAIA）。西武は福岡から所沢へ移ったばかりの新球団（根本陸夫が編成）○。
- 田淵は西武の主力に。真弓・若菜は阪神で頭角を現し、真弓は1985年の日本一に貢献 ○。

### 1979年 江川卓 ⇔ 小林繁（空白の一日）
- 野球協約の「交渉権は翌年のドラフトの前々日まで」の盲点を突き、1978年11月21日（ドラフト前日）に巨人が江川と契約 ○。
- セ・リーグ会長は契約を無効と裁定、巨人はドラフトを欠席、阪神が江川の交渉権 ○。
- 金子鋭コミッショナーが「いったん阪神と契約し、すぐ巨人へトレード」という「強い要望」○（Sportiva、Number）。
- 1979年1月31日、キャンプへ向かうはずの小林繁が空港から呼び戻され、阪神へのトレードを通告される。成立は同日23時30分、発表は日付が変わってから ○（Number）。
- 小林は1979年、22勝9敗、最多勝・沢村賞、古巣の巨人には8戦全勝 ○（デイリー、マイナビ）。

### 1985年 定岡正二（トレード拒否 → 引退）
- シーズン終了の翌日、電話で近鉄へのトレードを告げられる。拒否して29歳で引退（「巨人の定岡で終わりたい」）○（日刊ゲンダイ連載、Wikipedia）。
- 1981年11勝、1982年15勝、1985年は47試合に登板 ○（日刊ゲンダイ）。

### 1986年 落合博満 1対4（ロッテ → 中日）
- 1986年12月23日、落合博満 ⇔ 牛島和彦・上川誠二・平沼定晴・桑田茂 ○（Number）。
- 中日の監督に就いたばかりの星野仙一が仕掛けた ○。牛島は「ゴルファーになろうと」思うほど反発 △（回想）。
- 落合の年俸はロッテ時代の9700万円から1億3000万円に。「日本人初の1億円プレーヤー」とされる（野村克也の異説あり）○／△。
- 落合は三冠王3度（ロッテ時代）。牛島はロッテ1年目に24セーブ ○。

### 1993年 秋山幸二 3対3（西武 ⇔ ダイエー）
- 1993年11月、秋山幸二・渡辺智男・内山智之 ⇔ 佐々木誠・村田勝喜・橋本武広。仕掛けたのはダイエーの根本陸夫（西武の編成から移った人物）○（Number、SPAIA）。
- 佐々木誠は11月16日、日付が変わった深夜に連絡を受けた △（本人の証言）。
- 佐々木は1994年に西武で盗塁王 ○。秋山はダイエーの1999年日本一の中心に（広く知られる）○。

### 2003年 小久保裕紀 無償トレード（ダイエー → 巨人）
- 2003年はオープン戦で右ひざを痛め、一軍・二軍とも出場なし。ダイエーは日本一 ○。
- 日本一の優勝パレードの数日後、巨人への無償トレードが発表 ○（日付は記事で差：「翌日」「数日後」）。
- 本人：「選手会長として球団との交渉ごともあった」「球団の社長から嫌われた、というのが実際のところ」○（Number 本人証言）。
- 王貞治監督は本人からの電話で「絶句」、「球団の対応に疑問が残る」○（報道）。
- 2004年、巨人で125試合、打率.314、41本塁打、96打点。巨人の右打者で初の40本塁打 ○。
- 2006年オフに FA でソフトバンクへ戻る ○。

### 2011年 サブロー（ロッテ → 巨人）
- 2011年6月29日、サブロー ⇔ 工藤隆人＋金銭 ○（Number 2011/7/6）。
- 前年2010年にロッテは日本一。サブローは選手会長 ○。
- 巨人では登録名を本名の大村三郎に。7月1日の初打席で本塁打。出場48試合、在籍154日 ○。
- 同年オフに FA でロッテへ戻る ○。2016年引退。
- ロッテの重光昭夫オーナー代行：「まずいんじゃないかと思ったが、編成からの強い要望があった。今思うと間違いだった」○（デイリー）。

### 2021年 中田翔 無償トレード（日本ハム → 巨人）
- チームメートへの暴力行為で、日本ハムが無期限の出場停止処分 ○。
- 2021年8月20日、巨人が無償トレードで獲得と発表。翌21日に巨人で出場 ○（デイリー）。
- 「移籍で処分が事実上なくなった」と批判 ○（President、現代ビジネス、J-CAST）。

### 2026年 甲斐拓也 金銭トレード（巨人 → 楽天）
- 2024年オフ、ソフトバンクから FA で巨人へ。5年総額15億円（推定）○（デイリー 2024/12/27）。
- 人的補償で巨人の伊藤優輔投手がソフトバンクへ（2025年1月22日公示）○。
- 2025年は68試合、打率.260、4本塁打。2026年は13試合、先発マスクは3試合 ○（hb-nippon、ベースボールチャンネル）。
- 2026年10月30日、楽天へ金銭トレード。5年契約の2年目を終えたところ ○（hb-nippon）。
- 楽天は前日に捕手2人と来季の支配下契約を結ばないと発表していた ○。

### 1975年 張本勲（日本ハム → 巨人）
- 1975年オフ、張本勲 ⇔ 高橋一三・富田勝 ○（hb-nippon、SPAIA）。
- 長嶋茂雄監督の1年目（1975年）、巨人は球団史上初の最下位 ○。
- 張本は移籍1年目（1976年）に自己最多の182安打、王と「OH砲」。巨人はリーグ優勝 ○。
- 高橋一三は日本ハムで2度の2けた勝利を含む57勝 ○。

### 2009年 清水直行（ロッテ → 横浜）
- 2009年オフ、清水直行 ⇔ 那須野巧・齋藤俊雄 の1対2。清水は複数年契約の2年目での移籍 ○（SPAIA、ベースボールチャンネル）。
- 2010年に10勝 ○。

### 2016年 大田泰示（巨人 → 日本ハム）
- 2016年11月2日発表、大田泰示・公文克彦 ⇔ 吉川光夫・石川慎吾 の2対2 ○。
- 大田は移籍1年目からレギュラー、2019年 打率.289・20本塁打・77打点、2020年ゴールデングラブ賞 ○。
- 公文は中継ぎで定着。吉川（2012年パMVP）は巨人で3年間7勝 ○。
