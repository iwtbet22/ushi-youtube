# 4本目「黒い霧事件」構成案（約30分）

テーマ：1969〜1971年のプロ野球八百長事件を、「お金」と「制度（野球協約・永久追放）」の側から物語として描く。
主人公は池永正明。受け取った100万円を返さなかったことで永久追放となり、35年後に協約が変わって復権した。

## 作り方の変更（参考：政治解説チャンネルの冒頭の作り）
- 冒頭1分半は、黒い画面の一言 → 数字 → 単語の連打 → 問いを3つ → 登場人物紹介のオープニング → 「黒い霧事件・序」
- 本編は「第0章〜第6章」の物語として章を切る。章の扉に、章の題を筆文字で出す
- 字幕は、下の小さな文章とは別に、文ごとの要の単語を1つ大きく出す。ときどき口語の一言（「口止め料、550万円!?」など）
- 絵の切り替えを速くする（冒頭は1〜2秒ごと、本編も1枚の絵を長く出しすぎない）
- 話す速さを1分あたり約260字から約300字に上げる
- 名前の挙がった選手のうち、八百長を断った人（基満男・村上公康の主張、鈴木啓示）は、そのことをはっきり言う。公式の処分と本人の主張を混ぜない
