## 事件簿（候補10件・年代順）
1. **1990年オフ 落合博満の年俸調停**：希望2億7000万円、球団提示2億2000万円 → 調停は球団の言い分どおり。理由は「下位球団の経営安定」。2年後の高木豊は増額を勝ち取り、判断の違いが批判された
2. **1994年オフ 野茂英雄**：複数年契約と代理人（団野村）を求めて球団と対立 → 任意引退 → 1995年にドジャースへ。日本人メジャーの扉を開いた契約更改
3. **1997年 ソリアーノと広島**：調停の決定を拒否して任意引退 → ヤンキースが保有権を310万ドルで買い取ってメジャーへ
4. **2000年 代理人交渉が正式に認められる**：1985年に労働組合になった選手会が求め続けた結果（1本目・2本目とつながる）
5. **2006年オフ 中村紀洋**：60%減の提示 → 自由契約 → 中日と育成契約・年俸400万円 → 2007年 日本シリーズMVP
6. **2007年オフ 福留孝介「誠意は言葉ではなく金額」**：保留のあと、FAでカブスへ
7. **2010年オフ 杉内俊哉の保留**：交渉の席に置かれた録音機に不信感 → 翌年FAで巨人へ（2本目のランキング3位とつながる）。同じ年、涌井秀章が今のところ最後の年俸調停（2億5300万円を勝ち取る）
8. **2015年オフ 杉内俊哉 5億円 → 5000万円**：自ら減額を申し出た、9割減。当時の史上最大の減額
9. **2018年オフ 金子千尋 5億円減の提示**：プロ野球史上最大の減額提示 → 自由契約 → 日本ハムへ
10. **2019年オフ 中島宏之 87%減**：野手として史上最大の減額率／**2021年 田中将大 9億円**：史上最高年俸、2023年オフに4億2500万円減
