確認日：2026-10-20。

**確認度**
- ◎ 一次資料（規約本文・公式公示）で確認
- ○ 複数の二次資料が一致
- △ 二次資料のみ・資料によって数字が違う → 台本では幅を持たせた言い方にしている

## 制度

|---|---|---|

| ドラフトで決まるのは入団ではなく「選手契約の交渉権」 | ○ | 同上（新人選手選択会議規約に基づく、と記載） |

| 第1回は1965年。目的は戦力の均衡と契約金の高騰の抑制 | ○ | 同上 |
| 全球団同時指名＋重複抽選の方式は1978年から | ○ | 同上 |

| 2008年から高校生と大学・社会人のドラフトを一本化 | ○ | Wikipedia「プロ野球ドラフト会議」 |

| プロ志望届：高校生は高野連、大学生は所属の大学野球連盟へ提出。出していない学生は指名不可 | ○ | Wikipedia「プロ志望届」 |
| 高校生の受付は夏の甲子園閉幕後、締め切りはドラフト会議の2週間前 | ○ | 同上 |

| 独立リーグの選手は1年目から指名可能 | ○ | 同上 |
| 日本国籍の選手が海外プロを経由した場合も、原則ドラフト指名が必要 | ○ | 同上 |
| 田澤ルール（ドラフト拒否→海外の選手は一定期間NPBと契約不可）は2008〜2020年 | ○ | 同上 |
| 外国人選手はドラフト対象外（対象は日本国籍、または日本の中学・高校・大学などの在学経験者） | ○ | 同上 |
| その年の4月1日以降に退学した選手は、その年のドラフトで指名不可 | ○ | 同上 |
| 1巡目は入札抽選。外れた球団だけで再入札し、全球団決まるまで繰り返す | ○ | 同上 |
| 最多競合は8球団 | ○ | 同上（記録の項） |
| 2022年、12球団中9球団が1位指名を事前公表 | ○ | 同上 |
| 2巡目はその年の順位の逆順（ウェーバー）、3巡目は逆ウェーバー、以降交互 | ○ | 同上、ベースボールチャンネル |
| セ・パ同順位の先後は2019年から1年ごとに交代 | ○ | 同上（どちらが先かは年で変わるので、台本では年を特定していない） |
| 指名は原則1球団10人まで。合計120人未満なら11人目以降も可、120人で終了。独立リーグ・海外プロの選手は120人に含めない | ○ | Wikipedia「プロ野球ドラフト会議」 |
| 育成ドラフトはウェーバー・逆ウェーバーを交互、参加したい球団のみ | ○ | 同上 |
| 交渉権の期限は翌年3月末、社会人は翌年1月末 | ○ | 同上 |

| 再挑戦の道：大学は4年後、社会人は高卒なら3年後、独立リーグは1年目から | ○ | 上記ルールの組み合わせ |

## 育成選手

| 台本の内容 | 確認度 | 確認先 |
|---|---|---|
| 育成選手制度は2005年開始。背景の一つに社会人チームの休部・廃部 | ○ | Wikipedia「育成選手制度 (日本プロ野球)」 |
| 背番号は3桁、出場は二軍（ファーム）のみ | ◎ | 日本プロ野球育成選手に関する規約、Number 等 |
| 支配下選手は1球団70人まで。シーズン中の支配下登録は7月31日まで | ○ | Wikipedia、NPB の公示記事 |
| 育成として3シーズン在籍し、翌年度の支配下契約がなければ11月末で自由契約。その後、同じ球団や他球団と再契約できる | ◎ | 日本プロ野球育成選手に関する規約 第10条 |
| 支度金は標準でおよそ300万円 | ◎ | 同規約：標準額は290万円＋消費税 |
| 年俸の最低ラインは200万円台前半 | △ | 規約では230万円。240万円とする資料もあり、300万円への引き上げ議論も報じられている → 台本では金額を言い切らない |

## 台本から外したもの

| 内容 | 理由 |
|---|---|
| 「社会人選手は慣例として育成ドラフトで指名されない」 | 2006年以降は指名されていないとする記事と、育成で指名された社会人がいたとする記事が食い違い、現在も続いているか確認できなかったため |
| 育成選手の最低年俸の具体的な金額 | 資料によって230万・240万と違い、改定の有無も確認できなかったため |
| 2026年のドラフトでセ・パどちらが先か | 記事の中で記述が矛盾していたため |
| 1964年当時の大卒初任給との比較（5000万円の大きさを伝えるため） | 当時の初任給の確かな出典が見つからなかったため |
