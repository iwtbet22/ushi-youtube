録るのは **A. 冒頭（約1分20秒）** と **B. 締めのあいさつ（約20秒）** の2つだけです。
B は毎回同じ文なので、一度録れば次の回からも使い回せます。

## 録り方
- スマホのボイスメモで十分です。静かな部屋で、口から20〜30cm離して持ちます。
- **1行ずつ**、前後に1〜2秒あけて読んでください。
- 間違えたら、2秒ほど黙ってから**その行を最初から**読み直してください。言い直した部分はこちらで切ります。
- 音量・雑音・余分な間は、こちらで整えます。うまく読もうとしなくて大丈夫です。
- テンションは**ふだん人に説明するとき**くらいで十分です。張り上げなくていいです。
- 録れたら、Googleドライブに `ep05_A.m4a`、`ep05_B.m4a` のような名前で置いてください（形式は何でもOK）。

## 記号の意味
- `／` … 少し間をあける（息つぎ）
- `／／` … しっかり間をあける（1秒くらい）
- **太字** … 少しだけ強めに・ゆっくり
- （　）… 読み方
