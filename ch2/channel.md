# もうけの裏側：チャンネル紹介文・アイコン

## チャンネル紹介文（YouTube の「チャンネルの説明」にそのまま貼る）

誰でも知っている会社は、どこで、どうやって儲けているのか。
「もうけの裏側」は、決算短信・有価証券報告書・決算説明資料など、会社が公表している資料をもとに、お金の流れを読み解くチャンネルです。

・数字は、会社の公表資料から取り、どの決算期の数字かを必ず示します
・報道だけの数字は「報じられています」と分けて伝えます
・むずかしい会計の言葉は、なるべく使わずに説明します

1本目は、サイゼリヤ。安いのに、なぜ儲かるのか。利益の6割を稼いでいるのは、日本ではなくアジアでした。

身近な会社の「意外な稼ぎ方」を知りたい方は、ぜひチャンネル登録をお願いします。

※このチャンネルは、公開された資料をもとにした解説です。特定の会社の株の売り買いをすすめるものではありません。

（約400字。YouTube の上限は1000字）

### 短い版（ハンドル作成時・SNS のプロフィール用）
身近な会社の決算から、お金の流れを読み解く。数字はすべて会社の公表資料から。

## アイコン作成用のプロンプト

考え方：
- 表示はとても小さい（スマホでは直径40ピクセルほど）ので、形は1つ、色は2〜3色にする
- 文字はアイコンに入れない（画像生成AIは漢字を崩しやすい。入れるなら後から自分で「裏」1文字を重ねる）
- 会社のロゴ・商品・実在の人物は入れない
- 球界金融道と並べても別物に見えるよう、色と形を変える（野球のモチーフは使わない）

### 日本語で指示するとき（ChatGPT・Gemini など）
```
YouTubeチャンネルのアイコンを作ってください。テーマは「会社の決算から、もうけの裏側を読み解く」。
右下の角がめくれた1枚の紙の下から、金色の硬貨がのぞいている絵。背景は濃い紺色、紙は白に近い色、硬貨は金色。
シンプルな平面のイラストで、太くはっきりした形、丸く切り抜いても中央に収まる構図。スマホの小さな表示でも分かること。
文字・ロゴ・人物は入れない。正方形、2048×2048ピクセル。
```

### できあがったら確かめること
- 丸く切り抜いて、40ピクセルほどに縮めても形が分かるか
- 球界金融道のアイコンと並べて、別のチャンネルに見えるか
- 実在の会社のロゴや商品に似ていないか
