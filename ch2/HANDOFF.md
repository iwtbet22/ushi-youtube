# 2つ目のチャンネル 引き継ぎメモ（2026-11-17）

このメモは、1つ目のチャンネル「球界金融道」（プロ野球のお金と制度のしくみ）を作ってきたチャットから、
2つ目のチャンネルを新しいチャットで始めるための引き継ぎ。新しいチャットでは、まずこのメモと、
リポジトリ直下の CLAUDE.md（読みの点検の決まり）を読むこと。

## 1. なぜ2つ目のチャンネルを作るのか（持ち主の目標）
- どこにも雇われず、営業や人とのやりとりをできるだけせず、自分だけで月30万円を稼ぎたい。
  今は週3日・1日8時間のアルバイト。収入が生活費を3か月続けて上回ったらやめる考え。
- 収入の柱を分ける：1つ目のチャンネル（目標 月12万円）＋ 2つ目のチャンネル（目標 月10万円）＋
  英語の音声トラック＋ 電子書籍・有料記事＋ アフィリエイト。スポンサー・受託など、人とのやりとりが多いものは避ける。
- 見通しは1〜2年。数字は毎月末に確認する。

## 2. 2つ目のチャンネルの方針
- 題材：「会社のお金の裏側」。誰でも知っている会社の決算や公開資料から、「なぜ儲かる？」「なぜつぶれた？」を解説する。
  お金の話は広告の単価が高く、決算を調べて図にする今の作り方がそのまま使える。
- チャンネル名：「もうけの裏側」（2026年11月20日に決定）。1本目（c2ep01）は名前なしで書き出し済みのまま公開。2本目からは画面と登録のお願いに名前を出す（各回の NAME に入れる）。
- 型（1つ目で当たった型を持ち込む）
  - 問いかけ型：「◯◯は儲かってるのか？」（1つ目のセ・リーグ編・パ・リーグ編は4万回超えの再生）
  - 事件簿型：「経営破綻の事件簿」「大型買収の事件簿」など（1つ目の契約更改事件簿も4万回超え）
  - 意外な数字で引く（例：日本より海外で稼いでいる、球団は赤字でも球場は黒字）
- 試作1本目の候補（まだ持ち主の決定待ち。おすすめはサイゼリヤ）
  1. サイゼリヤ：安いのに、なぜ儲かる？（値上げしないのに稼ぐ仕組み、海外＝中国などアジアで稼いでいるという見方）
  2. ドン・キホーテ（PPIH）：なぜ長く増収増益が続く？
  3. ニトリ：長い連続増収増益は、なぜ止まったのか
- 1本目は試作。持ち主が見て「続けられる」と判断したら、チャンネルを作って月4本ほどから始める。
- 「量産型」と見られないこと（YouTube の収益化の規定）。本数より1本の深さ。会社ごとに必ず一次資料を調べる。

## 3. 調べものと事実の扱い（1つ目と同じ決まり）
- 調べたことは script/<回>_research.md に、確度の印をつけて書く：◎ 一次資料（決算短信・有価証券報告書・会社の発表）／○ 報道／△ 推定・幅のある報道／× 未確認
- 報道でしか確かめられない数字は、台本で「報じられています」「とされています」と言い切らない形にする。
- 事実確認表（script/<回>_factcheck.md）を作り、台本の数字をすべて出典と突き合わせてから書き出す。
- 会社の数字は信用に直結する。決算期（何年何月期か）を必ず添える。

## 4. 作り方（共通の道具。1つ目と同じリポジトリを使う）
- ファイルの置き場所
  - 台本・調査・概要欄：ch2/script/（例 ch2/script/c2ep01_narration.txt）
  - 場面のモジュール：docu/ に c2ep01.py のような名前で置く（docu の部品を import するため）
  - 写真：assets/ep02/img/（共通の置き場）。クレジットは assets/ep02/img/credits.json
- 場面の書き方は docu/ep12.py が最新の見本（SC・W・BIG・BARS・VB・TABLE・FLOW・MOVE・BULLETS・A（写真）など）。
  文ごとに要の言葉を大きく出し、文ごとに背景を替える。同じ写真は1本の中で1度しか使わない（check_unique）。
  画面のいちばん上の見出し・登録のお願いの場面にチャンネル名を出す（名前が決まってから）。
- 書き出しの手順
  1. python3 docu/film.py c2ep01 --check（字幕と要素の重なり）
  2. 読みの点検 4段階（CLAUDE.md）：check_yomi → check_kana（全文）→ 怪しい語は tools/check_words.py でまとめて聞き比べ
     - 名字だけ・名前だけの呼び方、「〜かち」（10勝〜90勝は readings.py で直してある）、「年◯億円」の「年」（とし と読まれやすい）に注意
  3. python3 docu/film.py c2ep01 --qa → output/qa_c2ep01/sheet_*.jpg を全部見る
     （文字のない場面、要素の重なり、日付の決まっていないカレンダー、事実と違う矢印がないか）
  4. bash tools/enc.sh c2ep01 <場面の数>（1080p・720p の確認用・380MB の分割・sha256 まで。止まっても再開できる）
  5. python3 docu/export_desc.py c2ep01（概要欄。チャプターは書き出しと同じ時間割で数える）
     ※ export_desc.py は今は script/ の下を見る作り。ch2 用に置き場所を切り替える手直しが必要
- 英語の音声トラック：script/<回>_en.txt（日本語の1文に英語1行）を書いて python3 docu/english.py <回>
  → output/upload/<回>_en_audio.mp3 と <回>_en.srt。YouTube Studio の「言語」→ 吹き替えに追加（上級者向け機能が必要）
- 写真：Wikimedia Commons の商用可・改変可のもの（CC BY / CC BY-SA / CC0 / PD）だけ。NC・ND・報道写真は使わない。
  tools/commons_info.py で検索とライセンス確認、tools/fetch_commons.py --api で取得。Wikimedia の制限に注意（間をあけて取る）。
  会社のロゴ・商品の写真は商標の扱いに注意し、店舗の外観など一般的なものにする。

## 5. 納品の形（1つ目と同じ）
- 音量 -14 LUFS、libx264 slow crf22、maxrate 8M、AAC 192k。確認用は 720p crf26。
- アップロード用は380MBごとに分割し、sha256 とつなぎ方（Windows: copy /b、Mac: cat）を添えて SendUserFile で送る。
- 動画ファイルは git に入れない（output/ は .gitignore 済み）。

## 6. 1つ目のチャンネルのアナリティクスで分かったこと（2026年10月20日〜11月14日）
- 当たった回：おすすめ（ブラウジング）からの再生が8〜9割。クリック率4〜5.7%、表示23万〜38万回。
- 外れた回（制度の解説）：クリック率1.6〜2.9%、表示1万回前後で止まる → 「知っている対象＋お金＋意外な数字」が強い。
- 視聴維持：最初の1〜2分で約45%が離れる → 冒頭は40秒以内に本題。最初の5秒で一番強い数字。
- 登録の7割近くは本編の再生ページで起きる。終了画面の登録ボタンのクリックは0〜0.1%（最後まで見る人は約1割）
  → 登録のお願いは途中に2回（3分ごろ・10分ごろ）。シリーズの名前を出して「次も見たい」理由を言う。
- ショートから本編への移動はほとんどない → ショートは最後を「チャンネル登録のお願い」で締める。
- 終了画面は再生リストに固定する。
