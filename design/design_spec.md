# デザイン仕様 v0.1（冒頭3分プロト）

参考動画のストーリーボード（約5秒間隔のサムネイル）を見て、**構成の型**だけを抜き出したもの。
参考動画の映像・図版・文字は一切使っていない。背景はすべてコードで生成し（`render/scenes.py`）、台本もオリジナル。

## 全体トーン
- 暗めのシネマ調。黒つぶれ寸前のシャドウ、彩度は控えめ、周辺減光、フィルムグレイン、漂う塵
- 1カット 4〜9秒。止め絵はゆっくりズーム／パン（ケン・バーンズ）で必ず動かす
- 基本はカットでつなぐ。キーワードカードの頭だけ白フラッシュ＋低音ヒット
- 構成リズム：映像だけのオープニング → 問いかけ → 赤黒のフックカード → 用語ごとに「キーワード → 用語ボックス → 図解」の順

## テロップ部品（`render/style.py`）
| 部品 | 用途 | 仕様 |
|---|---|---|
| 字幕ボックス `subtitle` | ナレーション字幕 | 左下配置、深いマゼンタ `rgba(120,22,78,.84)`、細い白枠、角丸12。Noto Sans JP Black 50px、白文字＋黒縁3px、2行まで |
| 強調色 | 字幕の中のキーワード | `【】` で山吹 `#FFC428`、`《》` で水色 `#78C8FF` |
| 用語ボックス `term` | 制度用語の定義 | 下中央。こげ茶の角丸ラベル（用語名）＋墨色の説明帯。説明文は中央揃え、2行 |
| キーワードカード `keyword` | 章の頭で単語を見せる | 中央に巨大な1語。`white`＝白明朝＋黒い影、`fire`＝橙グラデ＋グロー（強調したい回だけ使う） |
| フック `hook` | 問いかけを大きく見せる | 赤黒カード上に左下寄せ、太ゴシック118px、極太の黒縁 |
| タイトル `title_card` | サムネ兼用のタイトル | 上段は白銀グラデ、下段は赤グラデ＋白黒の二重縁 |
| 図解 `diagrams.py` | 金額比較・構造の説明 | 方眼紙の背景、筆文字（Yuji Syuku）の見出し、墨色の線、強調は朱 `#B0121E` |

## 音
- BGM：低いドローン＋Am系のパッド（`render/audio.py` で合成した仮の音）
- 効果音：フラッシュカット＝低音ヒット、テロップが出るシーン＝控えめなシュッ
- ナレーション：`render/tts.py`（edge-tts の ja-JP-KeitaNeural、話速+10%）で作った仮の声。喋っている間はBGMを約-8dB下げる
- シーンの長さは「読み上げ時間＋前後の間（0.35秒／0.55秒）」に自動で合わせる
- 字幕はナレーションを要約したもの（参考動画と同じく、全文は出さない）
