# デザイン仕様 v2（本編・白背景の解説スタイル）

参考動画のストーリーボードを見て、**テロップの出し方**を中心に構成の型を抜き出したもの。
参考動画のイラスト・素材・文章は使っていない。イラストはすべてコードで描いたオリジナル（`explainer/illust.py`）、台本もオリジナル。

## 画面の基本
- 背景は白。イラストとテロップだけで見せる。カメラの動きはなし
- 画面の4か所に役割を固定する
  - 左上：今の章タイトル（紺の丸ゴシック・白フチ、小さめ）
  - 右上：シリーズ名の赤い帯（白文字2行・白い細枠）。全編で出しっぱなし
  - 中央：イラスト、ラベル、図表
  - 下：字幕帯

## テロップの出し方（今回いちばん寄せた部分）
| 部品 | 出し方 |
|---|---|
| 字幕 `ui.subtitle` | 画面下いっぱいの半透明グレー帯。**ナレーションを要約せず全文**、白の丸ゴシック＋黒フチで中央揃え2行。**一文ごとに切り替え**、3行以上になる文は読点でページを分ける |
| ラベル `ui.label` | イラストの真上に、色付きの太い丸ゴシック＋白フチ。ナレーションがその言葉を言うタイミングで「ポン」と出る |
| 強調ワード `ui.big_word` | 黄色＋黒フチ（数字・結論）、赤の筆（用語）、赤ゴシック（驚き） |
| 吹き出し `ui.bubble` | 白地・黒フチの楕円。人物のセリフに使う |
| スタンプ `ui.stamp` | 斜めの赤文字（「指名漏れ！」など） |
| 赤丸・矢印 | グラフの注目点に手書き風の赤丸、流れは青い矢印 |
| 章タイトルカード | 章が変わるときに白地に大きな章タイトル＋オレンジの下線、チャイム音 |
| まとめ | 黒板にチョーク文字で、ナレーションに合わせて1行ずつ増やす |

## 動き
- 要素はナレーションの何文目で出るかを指定（`at`）し、少し行き過ぎて戻る「ポン」で出す。出るたびに小さなポップ音
- 棒グラフは下から伸ばす、赤丸は左から描く
- 字幕はフェードなしで切り替え

## 音
- ナレーション：edge-tts（ja-JP-KeitaNeural、+10%）の仮の声。一文ずつ合成し、その長さで画面のタイミングを決める
- BGM：明るいマリンバ風のループ（合成）。喋っている間は下げる
- 効果音：要素が出るときのポップ音、章が変わるときのチャイム

## ファイル
- 台本と画面構成：`explainer/episode.py`
- テロップ部品：`explainer/ui.py`、イラスト：`explainer/illust.py`
- 書き出し：`python3 explainer/engine.py` → `output/ep01_main.mp4`
